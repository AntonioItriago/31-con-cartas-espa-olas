# 🎴 El 31 - Baraja Española

**El clásico juego de cartas "El 31" adaptado como Telegram Mini App.** 
Suma 31 puntos con cartas del mismo palo, utiliza la estrategia del "toque" y cuida tus vidas para convertirte en el campeón de la mesa.

## ✨ Características
- 🃏 **Baraja Española Auténtica:** Reglas clásicas del 31 (Oros, Copas, Espadas y Bastos).
- 🤖 **IA Inteligente:** Juega contra bots con diferentes niveles de estrategia (2 a 6 jugadores).
- ❤️ **Sistema de Vidas:** Gestiona tus vidas y recupéralas viendo recompensas.
- 📱 **Telegram Mini App:** Integración nativa con la API de Telegram WebApp.
- 💰 **Monetización:** Integración completa con SDK de Monetag (Rewarded Ads).
- 🎨 **UI/UX Responsiva:** Diseño optimizado para móviles con animaciones fluidas.

## 🎮 Cómo Jugar
1. Elige el número de jugadores (2-6) y tus vidas iniciales.
2. En tu turno, roba del mazo o toma la carta del descarte.
3. Descarta una carta para mantener 3 en tu mano.
4. ¡Canta **31** para ganar al instante, o **toca la mesa** si crees que tienes la mejor puntuación!
5. *Regla especial:* 3 cartas del mismo número valen **30.5 puntos**.

## 🛠️ Tecnologías
- HTML5, CSS3 (Diseño responsivo y animaciones)
- Vanilla JavaScript (Lógica del juego e IA)
- Telegram WebApp API
- Monetag SDK (Publicidad recompensada)
